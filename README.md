This is a repository for the third week assignment of the course 'Introduction to Deep Learning' (5511) of the Master of Data Science at the University of Colorado Boulder. 
The subject is 'The Hispathologic Cancer Detection data set' on Kaggle. This is a data set of pathology images to be classified. 
Classification is dependent upon whether the image contains evidence of metastatic cancer.

For an optimal understanding the notebooks should be read in the following order:

#### Exploratory Data Analysis
1. 5511-pr-week3-eda.ipynb
2. 5511-pr-week3-eda-ii.ipynb

#### Model Training
3. 5511-pr-week-3-model-architecture.ipynb
4. 5511-pr-week-3-model-architecture-norm.ipynb
5. 5511-pr-week-3-model-architecture-norm2.ipynb

#### Model Evaluation
6. 5511-pr-week-3-model-architecture-eval.ipynb
7. 5511-pr-week-3-model-architecture-eval-i.ipynb
8. 5511-pr-week-3-model-architecture-eval-ii.ipynb

#### Model Scoring
9. 5511-pr-week-3-model-scoring.ipynb
10. 5511-pr-week-3-model-scoring-i.ipynb
 
The necessary data sets are:
- train_labels.csv
- a folder 'train' with .tif files  
- a folder 'test' with .tif files 

These data sets can be found on: https://www.kaggle.com/c/histopathologic-cancer-detection/overview
